**残高、ローソク足、注文、約定はすべて合成された DEMO データです。** 実際の取引アプリ、バックテスト、利益実績ではありません。

## 起動方法

Node.js 22 以降と npm が必要です。外部パッケージはありません。

```sh
npm ci --ignore-scripts
npm test
npm run build
npm start
```

`http://localhost:4173` を開き、Ctrl+C で停止します。別のローカルポートは `PORT=4174 npm start`。サーバーはループバックにのみ接続します。登録、パスワード、API キー、口座、環境設定ファイルは不要です。`name` と `YOUR_ACCOUNT_ID` は例示用です。

## 操作例

1. READY、合成価格 100 UNIT から始めます。
2. BUY、指値 99、数量 1 の模擬注文を作ります。
3. 「Следующий mock-шаг」で価格は 99、残高は 9901 UNIT、模擬保有は 1 DEMO になります。約定はシミュレーションです。
4. SELL を 101 に設定します。2 ステップで 98、101 となり、模擬 SELL が約定します。
5. 「Отменить mock-заявки」は未約定注文を取り消しますが、保有を閉じません。
6. STALE または UNAVAILABLE では操作が明示的に拒否されます。READY で再開し、「Сбросить демо」で初期化できます。

ホーム、システム、操作、イベント、口座の 5 ページがあります。状態は現在のタブのメモリだけに保存され、再読み込みで消えます。実際の取引、マーケットへの通信、取引キー、実口座への接続、ライブモード、収益計算はありません。模擬操作のラベルはロシア語で、この説明が操作に対応しています。

## 寄付と範囲

ホームには 10 言語の案内と、コピー可能な所有者の公開 EVM アドレスがあります。対応する EVM ネットワークのネイティブ通貨やトークン（利用可能な場合の USDT、USDC など）に限ります。送信前にネットワークとトークンを確認してください。法定通貨や EVM 以外の送金はこのアドレスでは受け取れません。デモはウォレットを接続せず、トランザクションも送信しません。寄付先は模擬取引口座とは別です。

Meridian Drift は元のプロジェクトの文章によるコンセプトで、画像のモックアップはありません。配色と配置は既存の Control Room を参考にしました。このデモは独立した Git 履歴を持ち、非公開データや本番サービスを含みません。

`npm run build` は許可された 8 ファイルだけを `dist/` に出力します。`npm run scan` はファイル、ビルド、すべての Git オブジェクトを調べ、検出内容の種類と場所だけを表示します。静的ホストでは `scripts/serve.mjs` のヘッダーを保持し、5 つのルートを `index.html` に向けてください。

## オフライン再生と因果順序

`npm run demo:replay` で合成イベントを表示できます。システム画面にも同じ結果があります。判断にはその時点で利用可能なデータだけを使い、後から届いたデータは見えません。古い状態では次の判断を拒否します。模擬約定には明示的な mock ステップが必要です。残高は架空で、実際の収益ではありません。
