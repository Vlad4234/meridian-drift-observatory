## स्थानीय रूप से चलाएँ

Node.js 22+ और npm चाहिए। किसी बाहरी पैकेज की आवश्यकता नहीं है।

```sh
npm ci --ignore-scripts
npm test
npm run build
npm start
```

`http://localhost:4173` खोलें; Ctrl+C से बंद करें। दूसरा स्थानीय पोर्ट: `PORT=4174 npm start`। सर्वर केवल लूपबैक पर सुनता है। पंजीकरण, पासवर्ड, API कुंजी, खाता या वातावरण फ़ाइल की ज़रूरत नहीं है। `name` और `YOUR_ACCOUNT_ID` उदाहरण हैं।

## प्रदर्शन का क्रम

1. READY और 100 UNIT की सिंथेटिक कीमत से शुरू करें।
2. BUY का लिमिट 99 और मात्रा 1 रखें।
3. “Следующий mock-шаг” दबाएँ: कीमत 99, बैलेंस 9901 UNIT और नकली होल्डिंग 1 DEMO होगी। यह केवल अनुकरण है।
4. SELL का लिमिट 101 रखें। अगले दो चरणों में कीमत 98 और 101 होगी और नकली SELL निष्पादित होगा।
5. “Отменить mock-заявки” खुले ऑर्डर रद्द करता है, होल्डिंग बंद नहीं करता।
6. STALE या UNAVAILABLE में चरण, ऑर्डर और रद्द करने की क्रिया स्पष्ट रूप से विफल होगी। READY से फिर शुरू करें; “Сбросить демо” सब रीसेट करता है।

पाँच पेज हैं: होम, सिस्टम, ऑपरेशन, इवेंट और अकाउंट। स्थिति केवल वर्तमान टैब की मेमरी में रहती है; रीलोड पर मिट जाती है। वास्तविक ट्रेड, बाज़ार अनुरोध, ट्रेडिंग कुंजी, असली खाते से संपर्क, लाइव मोड या रिटर्न की गणना नहीं है। सिमुलेशन के बटन रूसी में हैं; ऊपर के चरण उनके अर्थ बताते हैं।

## दान और सीमाएँ

होम पेज पर दस भाषाओं में संदेश और मालिक का सार्वजनिक EVM पता है, जिसे कॉपी किया जा सकता है। संगत EVM नेटवर्क की मूल मुद्रा और टोकन, जहाँ समर्थित हों वहाँ USDT और USDC सहित, भेजे जा सकते हैं। भेजने से पहले सही नेटवर्क और टोकन जाँचें। इस पते पर सामान्य फिएट मुद्रा या गैर-EVM ट्रांसफ़र स्वीकार नहीं होते। डेमो वॉलेट नहीं जोड़ता और ट्रांज़ैक्शन नहीं भेजता। दान का पता नकली ट्रेडिंग खाते से अलग है।

Meridian Drift मूल परियोजना में लिखित अवधारणा है, कोई दृश्य मॉकअप नहीं। रंग और लेआउट मौजूदा Control Room से अनुकूलित हैं। इस डेमो का अलग Git इतिहास है; निजी डेटा और प्रोडक्शन सेवाएँ शामिल नहीं हैं।

`npm run build` सिर्फ सात अनुमत फ़ाइलें `dist/` में बनाता है। `npm run scan` फ़ाइलें, बिल्ड और सभी Git ऑब्जेक्ट जाँचता है और समस्या मिलने पर केवल श्रेणी व स्थान दिखाता है। स्टैटिक होस्टिंग में `scripts/serve.mjs` के हेडर बनाए रखें और पाँच रूट को `index.html` पर भेजें।
