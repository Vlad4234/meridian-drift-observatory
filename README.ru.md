# Meridian Drift Observatory · демонстрационный пульт

Языки: [English](README.md) · [Русский](README.ru.md) · [Français](README.fr.md) · [Italiano](README.it.md) · [Deutsch](README.de.md) · [Українська](README.uk.md)

**Все балансы, свечи, заявки и исполнения — синтетические данные DEMO.** Это интерактивная демонстрация интерфейса, а не торговое приложение, бэктест или свидетельство реальной доходности.

## Запуск

Нужны Node.js 22+ и npm. Сторонних пакетов нет.

```sh
npm ci --ignore-scripts
npm test
npm run build
npm start
```

Откройте `http://localhost:4173`; остановка — Ctrl+C. Другой локальный порт: `PORT=4174 npm start`. Сервер слушает только loopback. Регистрация, пароль, API-ключ, аккаунт и файл окружения не требуются. `name` и `YOUR_ACCOUNT_ID` — демонстрационные метки.

## Пройдите сценарий

1. Начните с READY и цены 100 условных UNIT.
2. Разместите BUY с лимитом 99 и количеством 1.
3. Нажмите «Следующий mock-шаг»: цена 99, баланс 9901 UNIT, позиция 1 DEMO. Это лишь симуляция исполнения.
4. Разместите SELL по 101. Два шага дают 98 и 101, затем mock-исполнение SELL.
5. «Отменить mock-заявки» удаляет заявки, но не закрывает позицию.
6. Выберите STALE или UNAVAILABLE: шаг, размещение и отмена явно отклоняются. READY возобновляет сценарий, «Сбросить демо» очищает его.

Доступны пять разделов: главная, системы, операции, события и кабинет. Состояние хранится лишь в памяти вкладки; обновление сбрасывает его. Есть только синтетический цикл цен, ограниченная модель заявок и журнал действий. Нет реальных сделок, рыночных запросов, подписания, торговых ключей, кошелька, live-режима и расчёта доходности.

## Донаты и ограничения

На главной предусмотрено обращение на EN/RU/IT/FR/ES и место для публичной платёжной ссылки владельца. Пока адрес не настроен, страница прямо показывает, что отправить донат через неё нельзя. После настройки посетитель сможет открыть внешнюю ссылку; сам проект не проводит платежи. Доступны лишь валюты, криптовалюты, способы и сети, поддерживаемые выбранным платёжным сервисом. Проверяйте их перед переводом.

Концепция полевого архива Meridian Drift найдена в исходном проекте как текст, без визуального макета. Палитра и компоновка адаптированы из действующего Control Room. Это отдельный набор исходников с новой историей Git; приватные данные, производственные службы, лимиты и отчёты не включены.

`npm run build` создаёт семь разрешённых файлов в `dist/`. `npm run scan` проверяет дерево, сборку, метаданные и все Git-объекты, выводя только категорию и место находки. Для статического хостинга сохраните заголовки из `scripts/serve.mjs` и направляйте пять маршрутов на `index.html`.

Права описаны в [NOTICE.md](NOTICE.md). Владелец разрешил публичную демонстрацию; открытая лицензия на код не предоставлена.
