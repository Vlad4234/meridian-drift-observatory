Мови: [English](README.md) · [Русский](README.ru.md) · [Français](README.fr.md) · [Italiano](README.it.md) · [Deutsch](README.de.md) · [Українська](README.uk.md)

**Усі баланси, свічки, заявки та виконання — синтетичні дані DEMO.** Це інтерактивна демонстрація інтерфейсу, а не торговий застосунок, бектест чи доказ справжнього прибутку.

## Запуск

Потрібні Node.js 22+ і npm. Сторонніх пакетів немає.

```sh
npm ci --ignore-scripts
npm test
npm run build
npm start
```

Відкрийте `http://localhost:4173`; зупинка — Ctrl+C. Інший локальний порт: `PORT=4174 npm start`. Сервер слухає лише loopback. Реєстрація, пароль, ключ API, обліковий запис і файл оточення не потрібні. `name` та `YOUR_ACCOUNT_ID` — приклади.

## Сценарій

1. Почніть зі стану READY і синтетичної ціни 100 UNIT.
2. Розмістіть BUY із лімітом 99 і кількістю 1.
3. «Следующий mock-шаг» змінить ціну на 99, баланс на 9901 UNIT, позицію на 1 DEMO: це симуляція виконання.
4. Розмістіть SELL за 101. Два кроки дають 98 і 101, після чого SELL виконується в симуляції.
5. «Отменить mock-заявки» скасовує заявки, але не закриває позицію.
6. STALE або UNAVAILABLE явно відхиляє кроки, заявки й скасування. READY відновлює роботу; «Сбросить демо» очищує все.

Доступні п'ять сторінок: головна, системи, операції, події та кабінет. Стан зберігається лише в пам'яті вкладки; перезавантаження його скидає. Є фіксований цикл цін, обмежена модель заявок і журнал. Немає справжніх угод, запитів до ринку, підписування, торгових ключів, торгового гаманця, live-режиму чи розрахунку дохідності.

## Донати й межі

На головній передбачено звернення EN/RU/IT/FR/ES та публічне платіжне посилання власника. Поки посилання не налаштоване, сторінка прямо повідомляє, що надіслати донат через неї неможливо. Після налаштування відвідувач відкриває зовнішній сервіс; демонстрація не обробляє платежі. Доступні лише валюти, криптовалюти, способи та мережі, підтримувані цим сервісом. Перевірте їх перед переказом.

Meridian Drift — текстова концепція в початковому проєкті, без візуального макета. Палітру й компонування адаптовано з наявного Control Room. Проєкт має нову історію Git та не містить приватних даних або виробничих сервісів.

`npm run build` експортує сім дозволених файлів до `dist/`. `npm run scan` перевіряє файли, збірку, метадані та всі об'єкти Git і показує лише категорію й місце знахідки. Для статичного хостингу збережіть заголовки з `scripts/serve.mjs` і перенаправляйте п'ять маршрутів на `index.html`.
